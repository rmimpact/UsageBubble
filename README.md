# UsageBubble

A tiny menu bar system monitor for Apple Silicon Macs.

A ring next to the clock shows CPU (outer) and memory (inner). Click it for a bubble with:

- CPU, GPU, RAM and GPU memory
- a live CPU graph and a memory breakdown
- the apps using the most CPU, GPU and memory

The bubble updates live with smooth motion, and the app uses about 1% of one CPU core while its bubble is closed.

## Download

**[Download UsageBubble for Mac](https://github.com/rmimpact/UsageBubble/releases/latest/download/UsageBubble.pkg)** (always the latest version)

Open the installer and follow the steps. UsageBubble is installed in Applications and appears in your menu bar. It opens at login and keeps itself up to date, and you can change both in its settings (the gear in the bubble).

Requires a Mac with Apple Silicon and macOS 13 or later.

Signed with a Developer ID and notarized by Apple.

This repository only holds the releases.
